# checklist-run: профиль «Академія чарівних світів»

Обновлён: 2026-11-13. Источники: `CLAUDE.md`, `README.md`, `docs/` (ТЗ версии 1), `package.json`,
`.github/workflows/pages.yml`, `tools/`, опыт сессии разработки среза и MVP. Прошлых прогонов нет.

## §1 Проект
- Стек: Three.js 0.170, TypeScript 7, Vite 8, vite-plugin-pwa; Node 22. Сервера и базы данных нет —
  всё состояние игры в `localStorage` браузера.
- Структура: один пакет. `src/core` (модели, ввод, звук, сохранение), `src/world` (локация),
  `src/game` (героиня, персонажи, задания), `src/ui` (интерфейс, строки uk/ru), `public/models`,
  `public/voice`, `tools/` (проверки и конвейеры ассетов), `docs/` (ТЗ).
- Домены задач: `voice | learning | gameplay | world | arch | tech | assets | docs | mixed`
  (совпадают с префиксами требований `VOICE-`, `LEARN-`, `PLAY-`, `WORLD-`, `ARCH-`, `TECH-`).
- Язык артефактов прогона: русский. Код, комментарии и сообщения коммитов — английский.
  Тексты игры — украинский и русский, у каждой строки оба.
- Источник требований для Шага 1: `docs/` — один прогон на этап или его связную часть
  (`docs/20-roadmap.md`). В манифест переносится поле «Требование» карточки дословно, источник —
  идентификатор. Строка «Состояние» в карточке говорит, что уже сделано.
- `development-checklists/` в git: нет (в `.gitignore`); история прогона живёт в его PROGRESS.

## §3 Окружение и ловушки runner'а
- Сервисы: только сервер разработки. У основной сессии — `npm run dev -- --port 5173 --strictPort`.
  Проверка «поднято»: `curl -sI http://localhost:5173/ | head -1`.
- **Порты агентов.** Агент в своей рабочей копии поднимает свой сервер: чеклист A — 5181, B — 5182,
  C — 5183, всегда с `--strictPort`, и гасит его по PID перед отчётом. Порт 5173 агентам не трогать.
- **`node_modules` в рабочей копии нет.** Агент делает символьную ссылку на каталог основного дерева
  (`ln -s <корень>/node_modules node_modules`), а не `npm install`. Чеклист, меняющий `package.json`,
  ставит пакеты только через runner (§8).
- Автопрохождение идёт в настоящем Chrome (`/usr/bin/google-chrome`, headless, `--use-angle=gl`) на
  встроенной графике. Три прохождения одновременно тормозят друг друга, игра сама снижает качество
  графики, а ожидания в скрипте могут не дождаться. Упавшее при параллельном запуске прохождение
  перепроверять в одиночку, прежде чем считать поломкой.
- После переписывания истории git или переключения веток с изменением `public/` сервер разработки
  может отдавать HTML вместо моделей — перезапустить его.
- `pgrep -a` на этом хосте запрещён хуком. Искать процесс: `pgrep -f <шаблон>`, смотреть:
  `ps -o pid,etime,comm -p <pid>`. `pkill -f "vite …"` убивает и собственную оболочку — гасить по PID.
- Скриншоты и логи — в `<root>/logs/` или каталог вне репозитория, не в корень проекта.
- Доп. шаги Шага 0: `git config user.email` оканчивается на `users.noreply.github.com`;
  `git config core.hooksPath` равен `tools/hooks`; ветка — `dev`.
- Предупредить пользователя перед волнами: не коммитить и не переключать ветки в этом репозитории,
  не останавливать сервер на 5173.

## §4 Политики
- Изоляция агентов: `worktree` — правило хоста и `CLAUDE.md`. Чеклист агенту даётся абсолютным путём
  основного дерева.
- Тесты на волну: `full` — сборка и одно автопрохождение `mobile` на сумме волны. Волна, не тронувшая
  `src/`, `index.html`, `public/` и `vite.config.ts`, обходится сборкой.
- Git-флоу: работа в `dev`, коммит на чеклист. В `main` — только перемоткой и только по прямой команде
  пользователя в текущей сессии.
- Формат коммита: conventional через скилл `commit`, по-английски, без имени ребёнка; в теле —
  путь чеклиста и идентификаторы требований.

## §5 Scope
- Shared-writes (один исполнитель на волну):
  - `src/main.ts` — почти любая игровая задача; до разбора монолита (ARCH-05) узкое место;
  - `src/ui/strings.ts`, `src/core/save.ts`, `src/style.css`, `index.html`;
  - `package.json` + `package-lock.json`, `vite.config.ts`, `.github/workflows/pages.yml`;
  - `src/core/clips.json` и `public/voice/` — пишутся только конвейером озвучки;
  - `CLAUDE.md`, `CREDITS.md`, `docs/README.md`, `docs/20-roadmap.md`, `docs/21-open-decisions.md`.
- Сгенерированные файлы (в cap 8 не считаются, shared вместе с источником):
  `src/core/clips.json` ← `tools/gen_voice.py` + `voice/phrases.json`; `public/models/**` ← `tools/usd2glb.py`,
  `tools/pack_hero.mjs`; `dist/` (не в git).
- Миграций на волну: неприменимо. Смена формата сохранения — не больше одного чеклиста на волну.
- Expansions:
  - новая или изменённая строка интерфейса → `src/ui/strings.ts`, оба языка;
  - новая произносимая строка → `voice/phrases.json` и запись клипа (VOICE-06); без записи в `main` не идёт;
  - новая модель или звук → `CREDITS.md` (источник и лицензия CC0);
  - новая команда проверки → `package.json`, `CLAUDE.md` («Проверка перед коммитом»), §2 этого профиля;
  - изменение управления или экранов → `tools/shot.mjs`, если прохождение на это опирается;
  - выполненное требование → строка «Состояние» в его карточке в `docs/`.

## §7 Гейты качества
- Мутации обязательны: как в ядре, плюс всегда для генераторов заданий (`src/game/tasks.ts`), адаптивной
  сложности и миграций сохранения (`src/core/save.ts`) — там ошибка тихо даёт ребёнку неверный пример
  или стирает прогресс.
- Харнесс: до ARCH-01 команды юнит-тестов нет — мутации гонять через автопрохождение или разовую пробу
  в `<root>/logs/`, импортирующую модуль из `src/`. Кэш Vite (`node_modules/.vite`) мутацию не маскирует,
  сервис-воркер в режиме разработки выключен. Критерий «убит»: ненулевой код возврата проверки.
- Глобальные гейты (после каждой волны): `npm run build`; поиск по добавленным строкам слов из закрытого
  списка делает хук при коммите — если списка нет, runner говорит об этом пользователю.
- Финальные доп. проверки: автопрохождение `desktop` и `mobile`; размер `dist/` против предыдущего
  (`du -sh dist`); `git grep -n "http" -- src index.html` — внешних ссылок в игре нет.
- Доп. критерии успеха: ни одного штрафа, таймера ответа или потери наград; каждая новая строка
  на двух языках; у каждой новой модели запись в `CREDITS.md`.

## §8 Команды общего состояния (только runner, между волнами, после /sessions)
`npm install` / `npm ci`, `npm run build` в основном дереве, перезапуск сервера на 5173,
`python3 tools/gen_voice.py` (платный сервис, см. §10), пересборка моделей (`tools/usd2glb.py`,
`tools/pack_hero.mjs`), любой `git push`.

## §9 Доставка
- Push: `git push origin dev` — после прогона, с подтверждения пользователя; ничего не публикует.
- Публикация: `git checkout main && git merge --ff-only dev && git push origin main` — **только по прямой
  команде пользователя в текущей сессии**. Запускает сборку и обновляет игру на телефоне ребёнка.
  Условия: сборка и автопрохождение зелёные на этом коммите; все произносимые строки записаны.
- Гейты выкатки: нет. Откат — `git revert` и повторная публикация; флагов нет.
- Проверка после публикации: `gh run list --workflow pages.yml --limit 1` — `success`; автопрохождение
  по адресу `https://svv2602.github.io/academy/`. Сервис-воркер отдаёт старую версию до второго
  открытия страницы.
- Что проверяет только пользователь: поведение на настоящем Samsung S22 (касания, кадры, звук).
  До его ответа статус — «ждёт проверки на устройстве», не «проверено».

## §10 Данные
- Серверных данных и метрик нет. Статистика ребёнка — только в `localStorage` его телефона, ключ `amw-save`.
- Запреты (безусловные): имя ребёнка и личная почта пользователя — ни в файлы репозитория, ни в запросы
  к внешним сервисам, ни в сообщения коммитов.
- Платное: озвучка Gemini TTS (`tools/gen_voice.py`). Ключ — в переменной окружения, в репозитории его нет.
  Перед запуском назвать пользователю число строк; при ошибке 402 (баланс) — остановиться и сообщить.

## §12 Пограничные случаи для брифинга
- Сохранение: что будет с уже существующим сохранением на телефоне ребёнка? — прогресс терять нельзя,
  формат версионируется.
- Офлайн и обновление: как изменение доедет через сервис-воркер и работает ли оно без сети?
- Голос: появляются ли новые произносимые строки и чем они будут записаны? — без записи фраза звучит
  синтезатором устройства или не звучит вовсе.
- Два языка: есть ли текст и на украинском, и на русском; подставляется ли имя как переменная?
- Телефон: помещается ли это на экране 844×390 в альбомной ориентации, достаёт ли палец; что с касаниями
  в левых 40% экрана (зона джойстика) — прецедент: короткое касание слева не вело героиню.
- Производительность: сколько это добавляет треугольников и мегабайт первой загрузки?
- Ребёнок 6–7 лет: поймёт ли без чтения; есть ли подсказка после ошибки; нет ли штрафа или таймера?
- Адаптивность: к какому навыку относится задание и как меняется его уровень?
- Автопрохождение: сможет ли `tools/shot.mjs` пройти новый шаг, или его нужно научить?
- Лицензия: модель или звук — CC0, источник записан?
