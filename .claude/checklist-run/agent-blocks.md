# checklist-run: блоки промпта агента — «Академія чарівних світів»

Runner вставляет `[env]` и `[forbid-extra]` в промпт любого `[code]`-чеклиста и нужные тематические блоки.
`<порт>` подставляется по букве чеклиста: A — 5181, B — 5182, C — 5183.

[env]
## Окружение
Основное дерево: <корень> (там лежит чеклист; код ты пишешь
в своей рабочей копии).
- Сначала: `ln -s <корень>/node_modules node_modules`. Пакеты не ставить.
- Проверка типов и сборка: `npm run build > build.log 2>&1; echo $?`.
- Сервер: `npx vite --port <порт> --strictPort > vite.log 2>&1 &` — запомни PID и погаси его перед отчётом.
  Порт 5173 занят основной сессией, не трогай его.
- Автопрохождение мира: `node tools/shot.mjs http://localhost:<порт>/ shots-run mobile > e2e.log 2>&1`
  (2–4 минуты). Успех — дошло до финала и список ошибок консоли пуст. Обязательно после любого изменения
  игрового кода.
- Логи и скриншоты (`*.log`, `shots-run/`) в отчёт о файлах не включай — это не результат работы.
- `pgrep -a` на хосте запрещён: используй `pgrep -f <шаблон>` и `ps -o pid,etime,comm -p <pid>`.
- Следуй `CLAUDE.md` в корне и карточке требования в `docs/` — она авторитетнее чеклиста.

[forbid-extra]
- Не коммить, не переключай ветки, не трогай `main`.
- Не запускай `npm install`, `npm ci`, `tools/gen_voice.py`, `tools/usd2glb.py`, `tools/pack_hero.mjs` —
  это делает runner между волнами.
- Имя ребёнка — нигде: ни в коде, ни в текстах, ни в тестовых данных. В примерах используй «Зоряна».
- Никаких штрафов, таймеров ответа, потери наград, внешних ссылок.

[mutations-extra]
Юнит-тестов до ARCH-01 нет. Мутацию проверяй пробой, которая импортирует функцию из `src/`
(не копирует её), или автопрохождением. «Убит» = проверка вернула ненулевой код.

[main-ts]   - `src/main.ts` — монолит на ~680 строк, в волне его пишешь только ты. Правь точечно,
              не переставляй блоки: следующий чеклист будет править тот же файл.
[strings]   - Каждая строка в `src/ui/strings.ts` имеет украинский и русский текст; имя подставляется
              через `{, name}`. Новая произносимая строка — ещё и в `voice/phrases.json`.
[save]      - Формат сохранения версионируется (`src/core/save.ts`). Поле добавляется с миграцией
              со старой версии; старое сохранение обязано открыться без потери прогресса.
[touch]     - На телефоне левые 40% экрана — зона джойстика: короткое касание там — «идти в точку»,
              протяжка — джойстик. Новые кнопки в этой зоне проверяй автопрохождением в режиме `mobile`.
[perf]      - Целевое устройство — Samsung S22. Новая геометрия — через `InstancedMesh` по ячейкам, как
              в `src/world/scenery.ts`; до и после — `node tools/budget.mjs`.
[assets]    - Модели и звуки только CC0, источник — в `CREDITS.md`.
