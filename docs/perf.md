# Замер кадров на телефоне — к `TECH-06`

Требование `TECH-06`: на Samsung S22 в самой тяжёлой точке первого мира игра держит не меньше 45 кадров
в секунду на уровне качества `q1` или выше. Проверить это можно только на самом телефоне. Здесь — как
измерить и куда записать.

Замер занимает около 15 минут. Ребёнок для него не нужен: прогресс игры замер не меняет.

## Что показывает счётчик

В правом верхнем углу игры всегда видна мелкая строка, например:

    60 fps · q2 · 963k tris · 459 calls

- `60 fps` — кадров в секунду, обновляется раз в секунду. Это главное число.
- `q2` — уровень качества: `q2` — свечение и тени, `q1` — только тени, `q0` — без них.
- `963k tris` — сколько тысяч треугольников нарисовано за кадр, вместе с проходом теней.
- `459 calls` — число вызовов отрисовки.

При обычном запуске игра начинает с `q2` и сама снижает уровень, если три секунды подряд кадров меньше 34.
Параметр `?q=1` в адресе фиксирует уровень: игра его не меняет.

## Подготовка телефона

1. Режим энергосбережения выключен, телефон не на зарядке и не горячий.
2. Остальные приложения закрыты.
3. Записать, как настроен экран: «Настройки → Дисплей → Плавность движений» — «Адаптивная» (до 120 кадров)
   или «Стандартная» (60). От этого зависит потолок счётчика.
4. Игра открыта в Chrome по адресу с параметром (так уровень качества не меняется сам):

       https://svv2602.github.io/academy/?q=1

   Телефон — горизонтально. Сохранение у Chrome и у значка игры на рабочем столе общее: героиня
   появится там, где ребёнок её оставил.

## Три точки

Самые тяжёлые места мира найдены на компьютере 2026-11-14 (см. «Замер на компьютере» ниже).
В каждой точке:

1. Подойти героиней к названному месту.
2. Медленно повернуть камеру вокруг и остановиться в том направлении, где число перед `k tris` самое большое.
3. Не трогать экран одну минуту и смотреть на число перед `fps`.
4. Записать два числа: обычное (которое держится большую часть минуты) и самое низкое, которое мелькнуло.

| № | Где | Как найти |
|---|---|---|
| 1 | Грибной король | на поляне слева от стартовой, если смотреть на замок; самое тяжёлое место мира |
| 2 | Стартовая поляна | место, где героиня появляется в новой игре |
| 3 | Королева у замка | в дальнем конце мира, перед замком |

Если есть время — четвёртая точка: сундук за берёзами, слева от стартовой поляны.

## Второй проход — как играет ребёнок

Открыть игру по обычному адресу, без параметра: `https://svv2602.github.io/academy/`. Постоять по минуте
в тех же трёх точках. Записать число кадров и **уровень качества, который показывает счётчик в конце минуты**:
если игра сама опустилась с `q2` на `q1` или `q0`, это тоже результат.

## Что считается выполненным

- Первый проход (`?q=1`): в каждой из трёх точек обычное число кадров — не меньше 45.
- Второй проход: игра не опускается ниже `q1`.

Если хотя бы в одной точке меньше — бюджет не выполнен: нужна оптимизация и повторный замер.

## Замер на компьютере

Снят 2026-11-14 на коммите `32607e6`, окно 844×390, встроенная графика компьютера разработки. Числа —
показания счётчика (треугольники с проходом теней / вызовы отрисовки) в самом тяжёлом из восьми направлений
взгляда. Кадров в секунду на компьютере — 60 в каждой точке (потолок экрана), о телефоне они ничего не говорят.

| Сундук за берёзами | 999 / 423 | 1055 / 476 |
| Королева у замка | 957 / 417 | 1025 / 482 |
| Лис | 956 / 412 | 1042 / 480 |
| Стартовая поляна | 932 / 414 | 995 / 476 |
| Олень | 924 / 425 | 987 / 476 |
| Алтарь Кристалла | 922 / 402 | 961 / 449 |
| Единорог | 907 / 402 | 978 / 454 |
| Пруд | 899 / 406 | 978 / 459 |

Счётчик складывает основной проход и проход теней, поэтому его числа больше бюджета «треугольников
в кадре» из `docs/15-tech.md`: тот считается без теней скриптом `node tools/budget.mjs`. На стартовой поляне
при `q2` этот скрипт 2026-11-14 показал 689 тыс. в кадре и 315 тыс. в проходе теней — при бюджете 650 тыс.
