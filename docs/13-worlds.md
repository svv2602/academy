# 13. Миры — `WORLD-*`

Требования этого раздела — **рамочные**. Перед работой над каждым миром пишется и согласуется
с заказчиком его дизайн-документ `docs/worlds/world-N.md`: карта, персонажи с характерами, тексты реплик,
цепочки заданий, секреты, питомец. Только после этого мир раскладывается на чеклисты.
Первый чеклист каждого из миров 2–5 — серая сборка (WORLD-12).

## Шаблон мира

Каждый мир обязан содержать всё из этого списка; пункт без галочки — мир не готов.

| # | Что | Мера |
|---|---|---|
| 1 | Локация со своим обликом, небом, музыкой | узнаётся по одному скриншоту; кадр собран — WORLD-10 |
| 2 | Сюжетные персонажи с характером и своим голосом | 5 |
| 3 | Цепочка заданий у каждого персонажа | 3 задания, навыки по таблице мира |
| 4 | Виды заданий, разыгранные в мире | не меньше 3, из них 2 — новые для игры |
| 5 | Артефакт и сцена его возвращения | 1; мир оживает по мере возвращения магии — WORLD-09; вступление и сцена возвращения — заставки, WORLD-13 |
| 6 | Необязательные секреты | не меньше 3 |
| 7 | Существа, занятые своими делами | не меньше 3 видов |
| 8 | Питомец, которого можно найти | 1 |

## Распределение навыков по мирам

Математика идёт по лестнице из [11-learning.md](11-learning.md); адаптивная сложность общая для всех миров,
мир задаёт только то, **какие** задания в нём встречаются.

| Мир | Математика | Логика | Новые механики в мире |
|---|---|---|---|
| 1. Королевство фей | счёт, сложение, вычитание, сравнение | закономерности, лишнее, пары, порядок, сортировка, память | бабочки, поиск звёзд, постаменты, камни через ручей |
| 2. Зачарованный лес | числовой ряд, соседи числа | закономерности, найди отличия, сопоставление, внимательность, лабиринт | лабиринт из тропинок, следы на земле, говорящие деревья |
| 3. Подводное королевство | сравнение, сложение и вычитание, состав числа | пространственное мышление, поиск предмета, комбинации | плавание, поиск среди кораллов, замок с кодом из ракушек |
| 4. Сладкая страна | примеры до 20, сравнение чисел, счёт десятками | геометрические фигуры, сборка из частей | сборка пряничного домика, взвешивание конфет |
| 5. Небесные острова | всё пройденное, переход через десяток | сложные закономерности, маршрут, многоэтапные головоломки | мосты из облаков, полёт на корабле по маршруту |

### WORLD-09 — Мир оживает по мере возвращения магии
- **Приоритет · объём · этап:** medium · M · Э3
- **Основание:** решение 2026-11-14; главный критерий качества из [00-vision.md](00-vision.md).
  Сейчас облик первого мира меняется только в самом финале — радуга, свечение неба, немного общего света
  (`src/main.ts:605`, подтверждено кодом на коммите `f9c3d6d`); возвращение каждой части артефакта
  в мире ничего не меняет.
- **Требование:** у каждого мира есть один параметр «магия» от 0 до 1; он вычисляется из уже сохранённого
  прогресса, формат сохранения не меняется; по решению Q11 каждая возвращённая часть артефакта добавляет
  магии, а возвращённый артефакт доводит её до 1. От параметра зависят цвет неба и тумана, яркость света, сила качания растительности,
  яркость светящихся материалов и число мелких живых объектов (цветы, огоньки, бабочки). Новые модели
  и новые источники света для этого не добавляются. При магии 0 мир остаётся светлым и не пугающим.
- **Приёмка:** тест: параметр для заданных сохранений равен ожидаемому; после перезагрузки страницы
  он тот же. Кадры с одной точки облёта (WORLD-11) при магии 0 и 1 различаются сильнее порога, заданного
  в проверке автопрохождения, и основная сессия подтверждает разницу просмотром. Замер кадров при магии 1
  укладывается в бюджет TECH-06. Облик при магии 0 подтверждает заказчик.
- **Пишет:** описание первого мира (после ARCH-06 — `src/worlds/fairy/`: небо, свет, растительность),
  `tools/shot.mjs`. **Зависит от:** ARCH-06, WORLD-11.

### WORLD-11 — У мира есть облёт камерой по заданному пути
- **Приоритет · объём · этап:** medium · M · Э3
- **Основание:** решение 2026-11-14; `tools/fps.mjs` меряет кадры только в точке появления героини,
  а TECH-06 требует трёх точек мира; автопрохождение снимает экраны и задания, обзорных кадров мира

- **Требование:** мир задаёт путь камеры из 5–8 точек длительностью 10–15 секунд. При первом входе

  командой: автопрохождение сохраняет кадр с каждой точки пути, `tools/fps.mjs` меряет кадры во время
  пролёта.
- **Приёмка:** автопрохождение: первый вход — показ идёт и пропускается касанием, второй вход —
  показа нет, старое сохранение — показа нет; в `shots-e2e/` есть кадры всех точек пути;
  `tools/fps.mjs` печатает наименьшую и среднюю частоту кадров по пути; реплика записана голосом.
- **Пишет:** описание первого мира, `src/game/camera.ts`, `src/core/save.ts` (отметка «показано»),

  **Зависит от:** ARCH-05, ARCH-06, ARCH-07, ARCH-11, VOICE-06.

### WORLD-13 — История рассказана в заставках из неподвижных кадров
- **Приоритет · объём · этап:** medium · M · Э3
- **Основание:** решение заказчика 2026-11-14; аудит: сюжетная рамка (Кристалл, пять осколков) нигде не рассказана
  ребёнку как история — вступление состоит из одной реплики кота. Проба 2026-11-14: три кадра вступления,
  нарисованные моделью изображений по двум скриншотам игры, повторяют облик мира; сжатый кадр весит 40–90 КБ.
- **Требование:** вступление первого мира (4–6 кадров) и сцена возвращения Кристалла (2–3 кадра) показываются
  неподвижными картинками с медленным наездом; у каждого кадра одна реплика кота и субтитр на двух языках.
  Касание переходит к следующему кадру, кнопка «пропустить» закрывает заставку целиком. Вступление идёт один раз —
  для нового сохранения, перед облётом мира (WORLD-11); для сохранения, в котором игра уже начата, его нет.
  Просмотренную заставку можно открыть снова из книги.
  Кадры: в облике игры; без букв, цифр и интерфейса на изображении; осколков на кадре ровно пять; героиня
  не показана крупно и спереди — её внешность настраивается (PLAY-05), рассказчик — кот. Образцы для генерации
  снимаются без интерфейса и отладочной строки. В сборке кадр не тяжелее 100 КБ, все кадры мира вместе —
  не больше 1 МБ; кадры входят в кэш для работы без сети. В мирах 2–5 заставки делаются по тому же правилу,
  состав кадров — в дизайн-документе мира.
- **Приёмка:** автопрохождение: новое сохранение — вступление идёт, листается касанием и пропускается кнопкой;
  начатое сохранение — вступления нет; заставка открывается из книги; проход без сети показывает все кадры;
  синтезатор не вызывается (реплики заставок записаны); вёрстка заставки проходит проверку в четырёх размерах
  экрана. Юнит-тест: вес каждого кадра и всех кадров мира в пределах; у каждого файла кадра есть запись
  в `CREDITS.md`. Кадры просмотрены исполнителем (профиль, §7 «Просмотр кадров») и приняты заказчиком с датой.
- **Пишет:** `public/story/*`, `src/game/story.ts` (новый), `src/core/save.ts` (отметка «показано»), строки мира,
  `voice/phrases.json`, `public/voice/*`, `index.html`, `src/style.css`, `tools/shot.mjs`, `vite.config.ts`
  (тип файла кадров в списке кэша), `CREDITS.md`.
  **Зависит от:** ARCH-05, ARCH-06, VOICE-06, WORLD-11. Q13 решён 2026-11-14: сгенерированные кадры разрешены
  на условиях из `CLAUDE.md` («Содержание игры»).

## Модели для миров 2–5

Узкое место — персонажи с анимацией. В бесплатных CC0-наборах нет детских пропорций и мало сказочных
существ (гномов, русалок, дракончиков). Для каждого мира до начала работ составляется список нужных
моделей с источником; если бесплатного источника нет, это решение заказчика (Q6).
