# Академія чарівних світів

Браузерная 3D-игра-приключение для ребёнка 6–7 лет (Three.js + TypeScript + Vite, PWA).
Готов **MVP первого мира — Королевства фей**: пять персонажей (единорог, лисичка, Грибной Король, олень,
Королева фей), у каждого цепочка из трёх заданий (десять типов мини-игр на панели и два задания прямо в мире),
пять осколков Кристалла света и финальная сцена в беседке. Сложность подстраивается сама, ошибки не штрафуются,
после ошибки кот показывает подсказку. Есть коллекция, родительский раздел (статистика, сложность, громкость),
звёзды, тайный сундук, сохранение.

Новый мир = список персонажей и шагов как в `src/game/quests.ts` плюс построитель сцены как `src/world/scenery.ts`;
задания (`src/game/tasks.ts`), сохранение и интерфейс общие.

    npm install
    npm run dev        # http://localhost:5173, с телефона в той же сети — адрес Network из вывода
    npm run build      # сборка в dist/ (относительные пути, годится для GitHub Pages)
    npm test           # юнит-тесты (Vitest), около секунды
    npm run e2e        # сборка и полное прохождение мира на телефоне и компьютере, проверка запросов и ссылок;
                       # около 5,5 минуты; флаги — npm run e2e -- --help

    node tools/shot.mjs http://localhost:5173/ shots desktop|mobile   # полное прохождение мира со скриншотами
    node tools/closeup.mjs http://localhost:5173/ shots               # крупные планы
    node tools/budget.mjs                                             # на что уходят треугольники в кадре
    node tools/fps.mjs q=2 q=1                                        # частота кадров по уровням качества
    node tools/pack_hero.mjs <src>                                    # пересобрать героиню из исходных glTF
    python tools/usd2glb.py <kit> public/models/nature2               # пересобрать набор природы из USD
    python3 tools/gen_voice.py                                        # озвучка voice/phrases.json (Gemini TTS)

Параметры URL: `?q=0|1|2` — зафиксировать уровень графики (иначе снижается сам при <34 fps).

Требования, этапы и открытые решения — в [`docs/`](docs/README.md); правила работы над проектом — в `CLAUDE.md`.
Разработка идёт в ветке `dev`, ветка `main` публикуется на GitHub Pages.

Структура: `src/core` — движковые вещи (модели, ввод, звук, сохранение), `src/world` — локация,
`src/game` — персонажи, `src/ui` — интерфейс и строки (uk/ru), `public/models` — CC0-модели (см. CREDITS.md).
