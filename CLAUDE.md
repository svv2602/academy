# Академія чарівних світів — правила проекта

Браузерная 3D-игра для ребёнка 6–7 лет (Three.js + TypeScript + Vite, PWA). Обзор и команды — в `README.md`.
Требования, этапы и открытые решения — в `docs/` (начинать с `docs/README.md`).

## Приватность — репозиторий публичный

- **Имя ребёнка никогда не попадает в репозиторий**: ни в код, ни в тексты реплик, ни в документы,
  ни в сообщения коммитов, ни в звуковые файлы. Имя — переменная, которая живёт только в сохранении
  на устройстве.
- Коммиты — только с адресом `noreply` GitHub; он настроен в локальном конфиге репозитория, не менять.
- Защита стоит в хуках `tools/hooks/` (проверяют добавленные строки, имена файлов, сообщение коммита
  и адрес автора). Включить один раз в каждой копии репозитория: `git config core.hooksPath tools/hooks`.
- Список запретных слов лежит вне репозитория: `~/.config/academy/private-words.txt`, по слову или основе
  слова в строке. Без списка хук предупреждает и пропускает. `--no-verify` не использовать.

## Ветки и публикация

- **Вся работа идёт в ветке `dev`.** Отправка `dev` в `origin` ничего не публикует.
- **`main` — это то, что стоит на телефоне ребёнка.** Каждая отправка в `main` пересобирает
  и обновляет игру (`.github/workflows/pages.yml`).
- В `main` попадает только проверенное состояние `dev`, перемоткой (`git merge --ff-only dev`),
  и **только по прямой команде пользователя в текущей сессии**. Разрешение из прошлой сессии не действует.
- Прямых коммитов в `main` нет.

## Проверка перед коммитом

    npm run build                                    # проверка типов и сборка
    npm run dev                                      # затем в другом терминале:
    node tools/shot.mjs http://localhost:5173/ shots mobile    # автопрохождение мира, ошибки консоли

Автопрохождение обязательно после любого изменения игрового кода. Команд `npm test` и `npm run e2e`
пока нет — они появятся по требованиям `ARCH-01` и `ARCH-02`.

## Язык

- С пользователем — по-русски.
- Голос в игре — украинский; интерфейс и субтитры — украинский и русский, у каждой строки оба текста.
- Комментарии в коде и сообщения коммитов — по-английски, как в существующей истории.

## Параллельная работа

- `src/main.ts` — общий файл почти для любой задачи: до его разбора (`ARCH-05`) в него пишет один
  исполнитель за раз.
- `src/ui/strings.ts`, `src/core/save.ts`, `src/style.css`, `index.html` — тоже общие.
- Агенты, меняющие файлы, работают в отдельных рабочих копиях и не коммитят; коммит делает основная
  сессия после проверки.
- Перед сборкой, установкой пакетов и отправкой в репозиторий проверять параллельные сессии.
- Волновые прогоны (`/checklist-run`) берут команды, порты агентов и общие файлы из
  `.claude/checklist-run/profile.md`.

## Содержание игры

- Никаких штрафов, таймеров ответа и потери наград.
- Никаких внешних ссылок, рекламы, регистрации.
- Модели и звуки — только CC0 или собственные; каждый источник записывается в `CREDITS.md`.
- Каждая новая произносимая строка должна быть записана голосом до публикации в `main`.
